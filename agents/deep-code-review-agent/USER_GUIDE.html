deep code review agent

Perform deep read-only code reviews and produce prioritized remediation tasks with structured review outcomes.

Agent: deep-code-review-agent Guide: USER_GUIDE.html Use with README + usage template

What This Agent Does

  • Review repository code and supporting files in read-only mode.
  • Produce prioritized task report with IDs (`P<priority>-<index>`).
  • Include required report sections:
  • Merge duplicate findings with explicit de-duplication rationale.
  • Support `Re-review` mode for tasks previously marked `RESOLVED`.
  • Publish structured review outcome events for handoff.

When To Use

  • Use when this agent's mission matches the current task in your project workflow.
  • Use when inputs can be provided clearly from repository context and tracker state.
  • Use this guide for quick orientation, then execute through the usage template.

Required Inputs

  • Repository root path
  • Review mode: `Full Review` or `Re-review`
  • `task_identifier`

Execution Flow

Read inputs and determine mode (`Full Review` or `Re-review`). -> Resolve tracking mode and per-issue state paths. -> Load latest role task packet: -> Run isolation preflight before any write: -> In `Full Review`, inventory repo structure and risk hotspots. -> Select chunking strategy based on repo size (single pass, module pass, or phased pass).
