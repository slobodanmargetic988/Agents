git worktree cleanup agent

Safely clean Git worktrees and related branches using a strict two-phase model: `plan` first, `apply` only after explicit user confirmation.

Agent: git-worktree-cleanup-agent Guide: USER_GUIDE.html Use with README + usage template

What This Agent Does

  • Discover all worktrees for a repository.
  • Produce a deterministic cleanup plan without changing anything.
  • Remove non-preserved worktrees in apply mode after confirmation.
  • Remove related branches that match cleanup patterns only when safe.
  • Enforce branch/worktree protection and merge safety checks.

When To Use

  • Use when this agent's mission matches the current task in your project workflow.
  • Use when inputs can be provided clearly from repository context and tracker state.
  • Use this guide for quick orientation, then execute through the usage template.

Required Inputs

  • `repo_root`
  • `preserve_worktree_path`
  • `protected_branches` (must include at least `main`, `master`, `develop` plus user additions)
  • `branch_cleanup_patterns` (default `codex/*`)
  • `mode` (`plan` or `apply`; default `plan`)
  • `plan_id` from previous `plan` output
  • `confirmation_token` entered by user
  • `execute_confirmation` exact phrase: `yes, execute cleanup`

Execution Flow

Validate required inputs and normalize paths/patterns. -> Validate repository context (`repo_root` is a Git repo). -> Discover worktrees (`git worktree list --porcelain`) and classify keep/delete candidates. -> Discover candidate branches from `branch_cleanup_patterns`. -> Remove from branch candidates anything protected, current, or not tied to cleanup scope. -> Evaluate branch merge safety (must be fully merged into preserved mainline branch).
