backend tester

Verify backend changes with deterministic readiness gating, evidence-backed results, and structured status/handoff events.

Agent: backend-tester Guide: USER_GUIDE.html Use with README + usage template

What This Agent Does

  • Execute backend validation based on requested scope (targeted or full).
  • In developer-handoff mode, run the fullest feasible suite for changed backend scope.
  • Add/update backend tests when coverage gaps are found.
  • Run lint, test, and build/compile checks for backend code.
  • Produce an issue-scoped backend test report.
  • Publish structured test outcome events for review routing.

When To Use

  • Use when this agent's mission matches the current task in your project workflow.
  • Use when inputs can be provided clearly from repository context and tracker state.
  • Use this guide for quick orientation, then execute through the usage template.

Required Inputs

  • `task_identifier`
  • `repo_root`
  • `default_branch`
  • `test_target`
  • Optional:
  • `stack_file_path`
  • `harness_mode` (`targeted`, `full`, `developer_handoff`)
  • `tracking_mode` (`linear` or `local`)

Execution Flow

Validate required inputs and changed-scope context. -> Resolve tracking mode and per-issue state paths. -> Resolve Linear workflow config and worktree policy. -> Load latest role task packet: -> Execute readiness gate before any test command: -> Run isolation preflight before any write:
